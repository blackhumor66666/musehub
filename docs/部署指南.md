# 部署指南

## 拿到三样凭据

### 1. 网易云 Cookie

1. Chrome 打开 https://music.163.com 并登录(建议扫码)
2. F12 → Network → 刷新 → 任选一个请求 → Request Headers → 复制整行 `Cookie:`
3. 填到 `.env` 的 `NETEASE_COOKIE=`

> Cookie 里必须能看到 `MUSIC_U=...`。有效期一般数月, 失效表现:
> Web 面板"自检"里网易云搜索正常但音源全失败 → 重新抓一次 Cookie 即可。

### 2. QQ 音乐 Cookie

1. Chrome 打开 https://y.qq.com 并登录
2. 同上复制 Cookie, 填到 `QQ_COOKIE=`
3. 找"我喜欢"歌单 ID: 打开你的"我喜欢"歌单页面, 地址栏形如
   `https://y.qq.com/n/ryqq/playlist/1234567890`, 把数字填到 `QQ_FAVORITE_DISSID=`

### 3. Navidrome

`.env` 填 `NAVIDROME_URL / NAVIDROME_USERNAME / NAVIDROME_PASSWORD`。
唯一要求: **Navidrome 扫描的音乐目录和 MuseHub 的 `MUSIC_DIR` 指向同一份文件**。

## 方案 A: 群晖/绿联等 NAS 的 Docker

```bash
# 在 NAS 上能跑 docker 的目录里
git clone <你的仓库> musehub   # 或直接拷贝 musehub 目录
cd musehub
cp .env.example .env && vi .env
docker compose up -d
```

`.env` 里 `MUSIC_DIR` 在容器内固定是 `/music`, 你只需要改
`docker-compose.yml` 里的挂载源:

```yaml
volumes:
  - /volume1/music:/music      # 换成你 NAS 的真实音乐目录
```

然后 Navidrome 也挂同一个 `/volume1/music`。

## 方案 B: Windows 电脑常驻运行

```powershell
cd C:\Users\you\musehub
python -m venv .venv
.venv\Scripts\pip install -r requirements.txt
copy .env.example .env
# .env 里: MUSIC_DIR=//DXP4800-79F5/music   (直接写 UNC 路径)
.venv\Scripts\python -m app serve
```

想开机自启: 建一个计划任务, 启动程序填
`C:\...\musehub\.venv\Scripts\python.exe`, 参数 `-m app serve`,
起始于 `C:\...\musehub`。

## 方案 C: 不想常驻, 挂 crontab / 计划任务

```bash
# 每 30 分钟同步一次(Linux crontab)
*/30 * * * * cd /opt/musehub && .venv/bin/python -m app sync >> data/cron.log 2>&1
```

Windows 计划任务同理, 命令换成 `python -m app sync`。

## 首次上线检查单

```bash
python -m app doctor      # ① 配置体检
python -m app selftest    # ② 平台连通性(搜索/音源/Navidrome)
python -m app sync --dry  # ③ 试运行: 看它"将要"做什么
python -m app sync        # ④ 确认无误后真跑一次
```

或在 Web 面板完成同样的事: 首页横幅会列出缺的配置 → 订阅歌单 → 看日志 → 切实盘。

## 验证四方同步

1. 手机网易云里收藏一首歌 → 等 `SYNC_INTERVAL_MINUTES`(或点"立即同步")
   → 文件出现在 `艺人/专辑/` 下 → Navidrome 里出现
2. 手机上取消收藏 → 再同步 → 本地文件消失, Navidrome 歌单里也消失
3. 在 Navidrome/文件管理里删掉那个文件 → 下一轮 `RECONCILE_INTERVAL_MINUTES`
   内自动去平台取消收藏(日志里能看到"本地文件已删除")

## 常见问题

**下载的都是 128k?**
→ Cookie 失效或没填; VIP 歌曲必须对应平台会员。

**QQ 歌单拉不到?**
→ 公开歌单免登录可读; 私密歌单需要 Cookie。自检页会显示平台状态。

**"待回推动作"里一直有失败项?**
→ 这是 QQ 收藏回推接口对部分账号不可用, 点"忽略"后手动处理即可,
网易云的不应该出现这种情况(出现说明 Cookie 失效)。

**Navidrome 里歌单是空的?**
→ Navidrome 还没扫描到新文件。面板/CLI 的 `selftest` 之外可手动触发:
Navidrome 后台 → 扫描, 或等 `ND_SCANSCHEDULE`。
